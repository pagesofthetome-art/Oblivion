Basic Primary Needs - compatibility settings for this load order (Oblivion Rebirth+)
Made by Claude (Cowork) on 2026-10-05. Install AFTER Basic Primary Needs 6.3 and let this win the file conflict.

Replaces "Basic Primary Needs for objects.ini" (BPN's own optional file, unchanged) plus additions:
 - Alcohol (type 12): Skyrim Ingredients Spiced Wine + Alto Wine, Shivering Isles Mead (shares the
   Alluring Wine Bottles mead model). Vanilla drinks are already recognised by BPN by FormID.
 - Raw food disease chance (type 21): Skyrim Ingredients raw rabbit leg, chicken breast, Abecean longfin;
   New Food herring, salmon, trout, carp, pork fillet.
Remove this mod to go back to BPN defaults.
